# ScrubPaws 농장 — 꼬질꼬질 목장 키우기

넓은 들판에 울타리를 치고 닭·양·돼지·소·말을 키우는 3D 농장 게임입니다.
잘 돌본 가축은 새끼를 낳고, 다 큰 가축을 팔아 번 돈으로 새 가축과 울타리, 장비를 삽니다. 밤에는 늑대와 곰으로부터 가축을 지켜야 합니다.
게임 본체는 `app/src/main/assets/index.html`이며 같은 폴더의 `three.min.js`와 함께 브라우저에서도 바로 실행됩니다.

## 플레이 방법

| 하는 일 | 방법 |
| --- | --- |
| 이동 | 화면 드래그 / 방향키·WASD |
| 먹이 주기 | 헛간 옆 건초 더미에서 건초를 들고(행동 버튼·스페이스) 울타리 안 여물통에 놓으면, 배고픈 가축이 와서 먹습니다. 한 번에 4마리 분, 여물통은 12마리 분까지 |
| 목욕 | 호스 버튼(X)을 누른 채 가축 쪽을 향하면 물이 뿌려져 깨끗해집니다 |
| 가축 옮기기 | 가축 옆에서 행동 버튼으로 들고, 다른 울타리 안에서 다시 눌러 내려놓습니다 |
| 날씨 장비 | 낮에 창고(헛간) 앞에서 행동 버튼으로 그날의 장비를 꺼내, 울타리 안에서 다시 눌러 설치합니다 |
| 트랙터 | 트랙터 옆에서 행동 버튼으로 타고 내립니다. 타고 있으면 건초 더미 옆에서 저절로 싣고, 여물통 옆을 지나면 저절로 채웁니다 |
| 상점 | 🛒 버튼(B). 여는 동안 시간은 멈춥니다 |
| 총 | 사냥총을 산 뒤 총 버튼(C) |

## 가축

| 가축 | 사는 값 | 파는 값(어른) | 자라는 시간 | 임신 기간 |
| --- | --- | --- | --- | --- |
| 닭 | 500원 | 약 420원 | 70초 | 40초 |
| 양 | 1,500원 | 약 1,300원 | 95초 | 55초 |
| 돼지 | 2,500원 | 약 2,200원 | 105초 | 60초 |
| 소 | 5,000원 | 약 4,500원 | 130초 | 75초 |
| 말 | 9,000원 | 약 8,200원 | 150초 | 90초 |
| 판다 | 20,000원 | 약 18,000원 | 170초 | 100초 |

- 배고픔과 더러움이 낮게 유지되면 행복도가 오르고, 가득 차면 같은 종류의 어른 짝이 같은 울타리에 있을 때 새끼를 뱁니다.
- 새끼는 자라서 어른이 되어야 팔 수 있습니다. 건강하고 행복할수록 비싸게 팔립니다(파는 값의 50~120%).
- 굶거나 너무 더러우면 건강이 떨어지고, 0이 되면 가축을 잃습니다.
- 울타리 하나에 최대 8마리. 울타리는 6개까지 살 수 있습니다(4,000원 ~ 32,000원).

## 희귀 가축

- 새끼는 가끔 **희귀 가축**(황금빛, 소는 얼룩무늬 춤추는 소)으로 태어납니다. 상점에서는 살 수 없고, 파는 값이 5배입니다.
- 어미의 만족도가 높을수록 확률이 오릅니다.

| 어미 | 만족도 0 | 만족도 100 |
| --- | --- | --- |
| 보통 가축 | 2% | 18% |
| 희귀 가축 | 10% | 40% |
| 희귀한 소 | 30% | 70% |

## 날씨

아침마다 날씨가 무작위로 바뀝니다(첫날은 화창). 우박은 3일째, 태풍은 5일째부터 나옵니다. 날씨의 영향은 낮 동안만 있습니다.

| 날씨 | 장비가 없을 때 | 막는 장비 |
| --- | --- | --- |
| 화창 | 영향 없음 | — |
| 땡볕 | 만족도가 떨어지고 빨리 배고파지며 건강이 조금 깎임 | 그늘막 |
| 흐리고 약한 비 | 조금씩 더러워짐 | 처마 |
| 비 | 빨리 더러워지고 만족도가 떨어짐 | 처마 |
| 바람 | 만족도가 떨어지고 여물통의 건초가 날아감 | 바람막이 |
| 우박 | 건강이 깎이고 만족도가 떨어짐 | 우박 그물 |
| 태풍 | 더러워지고 만족도·건강이 깎이며 건초가 날아감 | 태풍 버팀목 |

장비는 종류마다 세 등급이 있고, 상점의 "날씨 장비"에서 등급을 올립니다. 등급은 모든 울타리에 적용되지만 설치는 울타리마다 해야 합니다.

| 등급 | 값 | 막는 정도 | 버티는 시간 |
| --- | --- | --- | --- |
| 낡은 (창고에 기본 비치) | 무료 | 60% | 22초 — 낮 동안 여러 번 다시 설치 |
| 튼튼한 | 3,000원 | 85% | 50초 |
| 최고급 | 9,000원 | 100% | 하루 종일 |

날씨로는 건강이 15 아래로 떨어지지 않습니다. 설치한 장비는 다음 날 아침에 걷힙니다.

## 트랙터

15,000원. 걷는 것보다 1.7배 빠르고 건초를 24마리 분까지 싣습니다. 트랙터 없이도 건초를 손으로 나를 수 있습니다(한 번에 4마리 분).

## 낮과 밤

- 낮 75초, 밤 45초. 밤에는 가축이 잠들고 늑대가 들판 가장자리에서 내려옵니다. 4일째부터는 곰도 나옵니다.
- **횃불**(기본 지급): 밤에 저절로 켜집니다. 가까이 다가가면 늑대가 달아납니다. 곰은 훨씬 가까이 가야 합니다.
- **사냥총**(6,000원): 멀리 있는 늑대를 한 방, 곰은 두 방에 쫓습니다.
- **전기 울타리**(울타리마다 5,000원): 그 울타리에는 늑대와 곰이 들어오지 못합니다.
- 진행 상황(돈, 가축, 울타리, 장비)은 자동 저장됩니다.

## 구성

| 경로 | 설명 |
| --- | --- |
| `app/src/main/assets/index.html` | 게임 본체 (3D 장면 + WebAudio). 웹 글꼴만 온라인에서 받아 오며, 오프라인이면 기기 기본 글꼴로 표시됩니다 |
| `app/src/main/assets/three.min.js` | 3D 렌더링 라이브러리 three.js r149 (MIT 라이선스), 오프라인 실행을 위해 앱에 포함 |
| `app/src/main/assets/GLTFLoader.js`, `SkeletonUtils.js` | three.js 예제 모음의 모델 불러오기 도구 (MIT 라이선스) |
| `app/src/main/assets/*_model.js` | 양·소·춤추는 소·판다 3D 모델(뼈대와 동작 포함)을 각각 한 파일로 묶은 것 |
| `app/src/main/java/com/vegacitizen/scrubpaws/MainActivity.java` | 게임을 가로 전체 화면 WebView로 띄우는 액티비티 |
| `.github/workflows/android.yml` | 푸시할 때마다 디버그 APK를 빌드하는 GitHub Actions |

## 빌드

Android Studio로 이 폴더를 열어 실행하거나, 명령줄에서:

```bash
./gradlew assembleDebug
```

APK는 `app/build/outputs/apk/debug/app-debug.apk` 에 생성됩니다.
디버그 APK는 저장소의 `app/debug.keystore`(디버그 전용 키)로 항상 같은 서명을 받으므로, 새 빌드를 기존 앱 위에 덮어 설치할 수 있고 저장 데이터가 유지됩니다.
GitHub Actions 실행 결과의 `ScrubPaws-debug-apk` 아티팩트에서도 내려받을 수 있습니다.
