# ScrubPaws — 꼬질꼬질 대소동

엄마가 돌아오기 전까지 집 안의 애완동물들을 깨끗하고 건강하게 돌보는 게임입니다.
3D로 만든 안드로이드 게임입니다. 방과 동물, 주인공, 엄마가 모두 3D 모델이고, 앱 안에서 WebGL(three.js)로 그립니다.
게임 본체는 `app/src/main/assets/index.html`이며 같은 폴더의 `three.min.js`와 함께 브라우저에서도 바로 실행됩니다.

## 플레이 방법

- **이동**: 화면 드래그 / 방향키 · WASD
- **잡기** (스페이스 · Z): 가까운 동물을 머리 위로 들어 올립니다. 들고 있을 때 다시 누르면 내려놓습니다.
- **목욕** (C): 들고 있는 동물을 욕조로 던집니다. 잠시 기다리면 저절로 깨끗해져서 나옵니다.
- **먹이** (X): 들고 있는 동물을 먹이통으로 던집니다. 그 동물이 지금 원하는 것(자기 밥·간식·물)을 알아서 먹습니다.
- **운동** (V): 들고 있는 동물을 오른쪽 아래 운동 구역의 러닝머신으로 던집니다. 달리는 동안 살이 빠집니다.

동물을 들면 주인공 둘레에 흰 원이 생깁니다. 이 원 안에 있는 빈 시설로만 던질 수 있어서, 던지는 힘이 약할 때는 시설 가까이 걸어가야 합니다.
먹이통·욕조·러닝머신은 한 칸을 한 번에 한 마리만 쓸 수 있습니다.

| 신호 | 의미 | 해야 할 일 |
| --- | --- | --- |
| 벅벅 긁고 파리가 꼬임 | 더러움 | 잡아서 목욕 |
| 침 흘리며 낑낑, 꼬르륵 | 배고픔 | 잡아서 먹이 |
| 혀 내밀고 헥헥 | 목마름 | 잡아서 먹이 |
| 눈을 반짝이며 폴짝폴짝 | 간식 | 잡아서 먹이 |
| 몸이 포동포동, 느릿느릿 | 살찜 | 잡아서 운동 |
| 머리 위에 💢, 으르릉 | 스트레스 | 원인(배고픔·살·더러움)을 풀어 주기 |
| 먼지 구름 속에서 퍽! 팍! | 싸움 | 한 마리를 잡아 떼어 놓기 |
| 축 늘어져 콜록콜록 | 병 | 씻기고 먹여서 회복시키기 |

- 배고프지 않은 동물에게 먹이면 살이 찝니다. 살이 찔수록 몸이 커지고 움직임이 느려지며, 너무 찌면 건강이 깎입니다.
- 배고프거나 뚱뚱하거나 더러우면 스트레스가 쌓이고, 깨끗한 동물을 씻겨도 스트레스를 받습니다. 스트레스가 높을수록 싸움이 잦아집니다.
- 싸우는 동안에는 두 마리 모두 다치고 더러워집니다. 동물이 8마리 이상이면 스트레스가 없어도 가끔 싸웁니다.
- 더러운 동물은 다가가면 도망치고 가구 뒤에 숨기도 합니다.
- 동물마다 울음소리가 다르고 상태에 따라 다르게 웁니다. 왼쪽 아래 버튼으로 소리를 끄고 켤 수 있습니다.
- 동물 크기는 종류마다 실제 크기 비율을 따르며, 같은 동물은 어느 스테이지에서나 같은 크기입니다.
- 같은 종류라도 아이마다 평소 표정(귀여움·뚱함·졸림·싱글벙글·멍함·시크)과 목걸이 색이 다르고, 가끔 윙크하거나 하품합니다.
- 던져진 동물은 놀란 얼굴로 비명을 지르며 커졌다가 작아지면서 떨어집니다.
- 그림자가 켜진 고화질로 시작하고, 기기가 느리면 자동으로 그림자를 끄고 해상도를 낮춥니다.

## 엄마의 판정과 용돈

제한 시간이 끝나면 엄마가 돌아와 동물을 한 마리씩 채점합니다.
건강과 깨끗함이 점수가 되고, 배고픔·목마름·살은 감점입니다.
스테이지별 합격선(평균 / 최저)을 넘으면 칭찬을 받고 다음 스테이지로 넘어갑니다: 1단계 50 / 25점, 2단계 55 / 30점, 3단계 58 / 32점, 4단계 60 / 34점, 5단계 62 / 36점.
그렇지 않거나 동물이 쓰러지면 혼나고, 그 스테이지를 다시 도전합니다.

칭찬을 받으면 용돈을 받습니다. 동물 한 마리의 점수 1점이 10원이라서, 동물이 많고 만족도가 높을수록 많이 받습니다.

## 상점

스테이지 사이에 용돈으로 능력과 시설을 삽니다. 산 것은 다시 도전해도 유지됩니다.
돈, 산 능력과 시설, 다음에 할 스테이지는 기기에 저장되어 앱을 껐다 켜도 이어집니다. 시작 화면의 "새로 시작"으로 지울 수 있습니다.

| 항목 | 효과 | 단계 | 가격 |
| --- | --- | --- | --- |
| 이동 속도 | 걷는 속도 +12%씩 | 5 | 1,500 / 2,500 / 4,000 / 6,000 / 8,500원 |
| 던지는 힘 | 던지는 거리 170에서 +95씩, 큰 동물을 들어도 덜 느려짐 | 5 | 위와 같음 |
| 먹이통 | 1개 → 3개 | 2 | 4,000 / 9,000원 |
| 욕조 | 1개 → 3개 | 2 | 4,000 / 9,000원 |
| 러닝머신 | 1대 → 3대 | 2 | 5,000 / 10,000원 |

## 스테이지

스테이지마다 종류별로 두 마리씩 나옵니다.
앞 스테이지일수록 쉽습니다. 배고픔·목마름·더러움·스트레스가 차는 속도가 1단계 50%, 2단계 60%, 3단계 66%, 4단계 74%, 5단계 82%입니다. 스트레스 없이도 가끔 싸우는 것은 동물이 10마리 이상인 3단계부터입니다.

1. 꼬마 친구들 — 햄스터, 병아리, 토끼 (6마리)
2. 말썽꾸러기들 — 토끼, 고양이, 강아지 (8마리)
3. 마당 식구들 — 리트리버, 돼지, 염소 (10마리)
4. 커다란 친구들 — 조랑말, 알파카, 판다 (10마리)
5. 집이 좁아요! — 곰, 하마, 아기 코끼리 (12마리)

## 구성

| 경로 | 설명 |
| --- | --- |
| `app/src/main/assets/index.html` | 게임 본체 (3D 장면 + WebAudio). 웹 글꼴만 온라인에서 받아 오며, 오프라인이면 기기 기본 글꼴로 표시됩니다 |
| `app/src/main/assets/three.min.js` | 3D 렌더링 라이브러리 three.js r149 (MIT 라이선스), 오프라인 실행을 위해 앱에 포함 |
| `app/src/main/assets/GLTFLoader.js`, `SkeletonUtils.js` | three.js 예제 모음의 모델 불러오기 도구 (MIT 라이선스) |
| `app/src/main/assets/cat_model.js`, `rabbit_model.js` | 고양이·토끼 3D 모델(뼈대와 동작 포함)을 각각 한 파일로 묶은 것 |
| `app/src/main/java/com/vegacitizen/scrubpaws/MainActivity.java` | 게임을 가로 전체 화면 WebView로 띄우는 액티비티 |
| `.github/workflows/android.yml` | 푸시할 때마다 디버그 APK를 빌드하는 GitHub Actions |

## 빌드

Android Studio로 이 폴더를 열어 실행하거나, 명령줄에서:

```bash
./gradlew assembleDebug
```

APK는 `app/build/outputs/apk/debug/app-debug.apk` 에 생성됩니다.
디버그 APK는 저장소의 `app/debug.keystore`(디버그 전용 키)로 항상 같은 서명을 받으므로, 새 빌드를 기존 앱 위에 덮어 설치할 수 있고 저장 데이터가 유지됩니다.
GitHub Actions 실행 결과의 `ScrubPaws-debug-apk` 아티팩트에서도 내려받을 수 있습니다.
