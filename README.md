# ScrubPaws — 꼬질꼬질 대소동

엄마가 돌아오기 전까지 집 안의 애완동물들을 깨끗하고 건강하게 돌보는 게임입니다.
게임 본체는 `app/src/main/assets/index.html` 파일 하나이며, 브라우저에서 열면 바로 플레이할 수 있습니다.
안드로이드에서는 이 파일을 전체 화면 WebView로 띄우는 앱으로 실행됩니다.

## 플레이 방법

- **이동**: 화면 드래그 / 방향키 · WASD
- **잡기** (스페이스 · Z): 가까운 동물을 머리 위로 들어 올립니다. 들고 있을 때 다시 누르면 내려놓습니다. 동물이 없고 어질러진 곳이 가까우면 치웁니다.
- **먹이** (X): 들고 있는 동물에게 줄 것을 고르면(숫자키 1~5) 조리대 쪽으로 던져서 먹입니다.
- **목욕** (C): 들고 있는 동물을 욕조로 던집니다. 잠시 기다리면 저절로 깨끗해져서 나옵니다. 욕조에는 두 마리까지 들어갑니다.

| 신호 | 의미 | 해야 할 일 |
| --- | --- | --- |
| 벅벅 긁고 파리가 꼬임 | 더러움 | 잡아서 목욕 |
| 침 흘리며 낑낑, 꼬르륵 | 배고픔 | 잡아서 먹이 → 그 동물의 밥 |
| 혀 내밀고 헥헥 | 목마름 | 잡아서 먹이 → 물 |
| 눈을 반짝이며 폴짝폴짝 | 간식 | 잡아서 먹이 → 간식 |
| 축 늘어져 콜록콜록 | 병 | 씻기고 먹여서 회복시키기 |

- 방 하나에 조리대(밥·간식·물)와 욕조가 모두 있습니다.
- 동물마다 울음소리가 다르고, 배고픔·목마름·조르기·놀람·화남·아픔에 따라 다르게 웁니다. 왼쪽 아래 버튼으로 소리를 끄고 켤 수 있습니다.
- 더러운 동물은 다가가면 도망치고 가구 뒤에 숨기도 합니다.
- 밥은 동물 종류마다 다릅니다.
- 원하지 않는 동물에게 먹이거나 다른 종의 밥을 고르면 집이 어질러져 모두 더 빨리 더러워집니다.
- 더러운 채로 두거나 굶기면 건강이 깎입니다.

## 엄마의 판정

제한 시간이 끝나면 엄마가 돌아와 동물을 한 마리씩 채점합니다.
평균 65점 이상이고 모든 동물이 40점 이상이면 칭찬을 받고 다음 스테이지로 넘어갑니다.
그렇지 않거나 동물이 쓰러지면 혼나고 게임이 끝납니다.

## 스테이지

스테이지마다 종류별로 두 마리씩 나옵니다.

1. 꼬마 친구들 — 햄스터, 병아리, 토끼 (6마리)
2. 말썽꾸러기들 — 토끼, 고양이, 강아지 (8마리)
3. 마당 식구들 — 리트리버, 돼지, 염소 (10마리)
4. 커다란 친구들 — 조랑말, 알파카, 판다 (10마리)
5. 집이 좁아요! — 곰, 하마, 아기 코끼리 (12마리)

## 구성

| 경로 | 설명 |
| --- | --- |
| `app/src/main/assets/index.html` | 게임 본체 (캔버스 + WebAudio). 웹 글꼴만 온라인에서 받아 오며, 오프라인이면 기기 기본 글꼴로 표시됩니다 |
| `app/src/main/java/com/vegacitizen/scrubpaws/MainActivity.java` | 게임을 가로 전체 화면 WebView로 띄우는 액티비티 |
| `.github/workflows/android.yml` | 푸시할 때마다 디버그 APK를 빌드하는 GitHub Actions |

## 빌드

Android Studio로 이 폴더를 열어 실행하거나, 명령줄에서:

```bash
./gradlew assembleDebug
```

APK는 `app/build/outputs/apk/debug/app-debug.apk` 에 생성됩니다.
GitHub Actions 실행 결과의 `ScrubPaws-debug-apk` 아티팩트에서도 내려받을 수 있습니다.
