# v5.0.0 — 실험실과 공룡

- 🧬 실험실 (레벨 7, 20,000원): 지으면 가축 사기 탭에 "공룡 복원"이 생겨요. 농장에 실험실 건물이 나타나요.
- 철 울타리 (레벨 7, 울타리 하나에 12,000원): 높은 울타리를 쇠창살로 바꿔요. 공룡은 철 울타리 안에서만 키울 수 있어요. 실험실이 있어야 살 수 있어요.
- 초식 공룡: 프로토케라톱스(레벨 7, 18,000원) → 트리케라톱스(레벨 9, 40,000원) → 브라키오사우루스(레벨 11, 80,000원)
- 육식 공룡: 콤프소그나투스(레벨 8, 25,000원) → 벨로키랍토르(레벨 10, 55,000원) → 티라노사우루스(레벨 12, 120,000원)
- 🥩 고기 (10개 800원, 씨앗·비료 탭): 육식 공룡은 고기만 먹어요. 사면 창고에 들어가요.
- 공룡은 새끼를 낳지 않아요. 사진을 찍어 관람료를 받아요.
