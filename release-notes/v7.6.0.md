# v7.6.0 — 타고 다니며 사냥하고 잡기

- 빠른 이동: 트랙터·비행기·말을 탄 채로, 실은 가축과 함께 이동. 배는 선착장(또는 낚시터 다리)에 묶어 두고 이동
- 숲·산악·초원·들판 정류장은 그대로 한 번 가 봐야 열림
- 트랙터·말로 달리다 부딪치면 야생 동물이 다치거나 죽음(트랙터 3, 말 2 피해). 잡으면 돈과 고기
- 밤의 맹수(여우·늑대 등)도 트랙터·말로 치면 잡힘
- 트랙터를 탄 동안에는 맹수가 습격해도 다치지 않고, 오히려 맹수가 다침
- 가축과 부딪치면 다치지는 않지만 놀라서 비켜나고 기분 -8
- 비행기 그물(🔄로 고르기): 위에서 던져 야생 동물을 산 채로 잡기. 작은 동물일수록 잘 잡히고, 맹수·희귀 동물은 어려움. 팔기·보호소·놓아주기
- 상호작용 보완: 맹수도 횃불·물호스·비행기 물 뿌리기·불을 보면 물러남, 야생 동물은 불을 피해 달아남, 총이 빗나가면 야생 동물이 놀라 달아나고 가까운 맹수는 사나워짐
- 토끼·사슴·노루·멧돼지가 밭에 들어와 작물을 뜯어 먹음. 다가가 쫓거나 덫·허수아비로 막기
