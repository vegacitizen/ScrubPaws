# v5.6.0 — 농업용 비행기

- ✈️ 농업용 비행기 (40,000원, 레벨 8): 시설·장비 탭의 도구·장비 묶음에서 사요. 세워 둔 비행기 옆에서 [비행기 타기], 울타리 밖에서 [착륙하기].
- 걷는 것보다 3배 빨리 날아서 농장 어디든 금방 가요. 내린 자리에 비행기가 서 있어요.
- 날면서 [뿌리기]를 누르면 아래 넓은 범위에 한꺼번에 뿌려요: 밭에 물과 비료, 울타리 여물통에 먹이(건초 더미와 창고에서), 물통에 물(물탱크에서).
- 육식 공룡 울타리 위에서 뿌리면, 어린 공룡에게는 고기를 여물통에 채우고, 다 큰 공룡이 배고프면 먹이용 울타리의 가축을 공룡에게서 먼 구석에 떨어뜨려요. 하늘에서는 물리지 않아요.
