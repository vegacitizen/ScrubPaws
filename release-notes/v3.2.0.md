## v3.2.0 — 농장 레벨

- 농장 레벨: 가축을 키우고, 얻고 수확하고, 도감을 채우고, 울타리를 넓히면 경험치가 올라 레벨이 오릅니다 (최고 12)
- 레벨이 오르면 상점에 새 가축·씨앗·울타리·시설·총·보호 장비가 차례로 나타납니다. 아직 열리지 않은 것은 목록에 보이지 않습니다
- 창고 증축(3단계): 작물 보관 용량과 건초 더미가 커지고, 트랙터·큰 트랙터를 들일 수 있습니다
- 여물통·물통 넓히기 (12 → 20 → 30칸)
- 큰 트랙터 (건초 48, 더 빠름)
- 레벨이 오를 때 축하금과 새로 열린 것 안내, 화면에 레벨과 경험치 막대, 목표·주문에도 경험치
- 쇠스랑은 레벨 2부터, 자격증 2·3급은 레벨 7·10부터
