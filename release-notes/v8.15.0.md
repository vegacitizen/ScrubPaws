# v8.15.0 · 손맛 나는 낚시와 수확

## 낚시
- ❗가 떠서 당긴 뒤에 **끌어올리기 연타**가 시작돼요. 물고기가 클수록 더 여러 번(3~12번) 빠르게 눌러야 하고, 시간 안에 못 채우면 놓쳐요.
- 깊은 물일수록 큰 놈이 물어요: 웅덩이 < 저수지 < 큰 호수. 큰 놈일수록 값이 더 나가요(연타 한 번당 +6%).
- 낚싯줄과 찌가 보이고, 걸리면 물고기가 물 위에서 펄떡여요. 주인공은 낚싯대를 든 채 기다리다가 누를 때마다 잡아채고, 잡으면 만세를 해요.
- 머리 위에 끌어올린 정도(노란 막대)와 남은 시간(파란 막대)이 나와요.

## 가축에게서 얻기
- 털 깎기 · 젖 짜기 · 달걀 줍기 같은 일을 하는 동안 버튼이 "연타!"로 바뀌어요. 누를 때마다 손이 빨라지고 털 · 물방울이 더 튀어요.
- 세 번 넘게 누르면 진행 막대가 금빛이 되고, 끝날 때 **솜씨 보너스**(20원 + 레벨×10원)를 받아요. 누르지 않아도 예전처럼 저절로 끝나요.
- 가축 위에 진행 막대가 보여요.
