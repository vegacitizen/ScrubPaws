# v6.3.0 — 상황에 맞는 고전 음악

배경 음악을 고전 음악 11곡으로 바꿨어요. 녹음 파일을 쓰지 않고 악보를 넣어 게임이 직접 연주하기 때문에, 앱 크기가 거의 늘지 않고 상황에 따라 곡과 빠르기를 바꿀 수 있어요.

| 상황 | 곡 |
|---|---|
| 아침(해 뜬 직후) | 그리그 「아침의 기분」 |
| 화창한 낮 | 베토벤 「환희의 송가」, 바흐 음악 수첩 미뉴에트 G장조, 비발디 「봄」, 모차르트 「아이네 클라이네 나흐트무지크」, 파헬벨 「캐논」 |
| 땡볕 | 파헬벨 「캐논」, 미뉴에트 |
| 비·흐림 | 사티 「짐노페디 1번」, 베토벤 「엘리제를 위하여」 |
| 바람 | 「엘리제를 위하여」, 「봄」 |
| 우박·태풍 | 베토벤 교향곡 5번 「운명」 |
| 고요한 밤 | 브람스 「자장가」, 「짐노페디 1번」 |
| 맹수가 나타난 밤 | 그리그 「산왕의 궁전에서」 (맹수가 많을수록 빨라져요) |

- 상황이 바뀌면 지금 곡이 서서히 줄고 새 곡이 시작돼요. 한 곡이 끝나면 3초쯤 쉬고 같은 상황의 다음 곡으로 넘어가요.
- 상점이나 메뉴를 열면 음악이 작아져요.
- 작곡가는 모두 세상을 떠난 지 70년이 넘어 곡의 저작권이 끝났어요(가장 최근이 1925년에 세상을 떠난 사티). 남의 연주 녹음은 쓰지 않았어요.
