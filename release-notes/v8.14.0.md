# v8.14.0 · 틸트로 보는 각도 바꾸기

- **두 손가락을 나란히 위아래로 끌면** 내려다보는 각도가 바뀌어요. 위로 끌면 눕혀서 멀리 보고(최저 24°), 아래로 끌면 위에서 내려다봐요(최고 90°, 바로 위). 기본은 50°예요.
- 두 손가락을 벌리고 오므리는 확대 · 축소는 그대로예요. 움직임이 벌리는 쪽인지 나란히 끄는 쪽인지 보고 알아서 구분해요.
- 키보드는 [ 와 ] (또는 PageUp · PageDown)로 바꿔요.
- 왼쪽 아래 🔍 단추에 각도가 함께 보이고, 누르면 확대와 각도가 모두 원래대로 돌아와요. 각도는 저장돼요.
