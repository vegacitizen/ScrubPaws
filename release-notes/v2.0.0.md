## v2.0.0 — 농장 키우기

게임 전체를 농장 키우기로 바꿨습니다.

- 넓은 들판과 울타리에서 닭·양·돼지·소·말을 키웁니다
- 잘 돌본 가축은 임신해 새끼를 낳고, 새끼가 자라면 팔 수 있습니다
- 가축을 팔아 번 돈으로 새 가축, 울타리(최대 6개), 장비를 삽니다. 가축은 들어서 다른 울타리로 옮길 수 있습니다
- 먹이: 건초 더미에서 건초를 날라 여물통에 놓으면 가축이 와서 먹습니다
- 목욕: 호스를 들고 가축에게 물을 뿌립니다
- 낮과 밤: 밤에는 늑대와 곰이 공격합니다. 횃불(기본), 사냥총, 전기 울타리로 지킵니다
- 이전 버전의 저장 데이터는 이어지지 않습니다
