# v6.5.0 — 공룡 넓이, 탈것으로 옮기기, 울타리·수량 지정 구매

## 공룡

- 공룡이 1.6배 빨리 걸어 다니고, 육식 공룡이 쫓아오는 속도도 1.35배가 됐어요.
- 공룡마다 필요한 울타리 넓이가 생겼어요(다 컸을 때). 기본 울타리는 177천이에요.

| 공룡 | 필요한 넓이 |
|---|---|
| 콤프소그나투스 | 20천 |
| 프로토케라톱스 | 30천 |
| 벨로키랍토르 | 50천 |
| 트리케라톱스 | 80천 |
| 티라노사우루스 | 150천 |
| 브라키오사우루스 | 170천 |

- 살 때는 다 컸을 때의 넓이가 남는 울타리에만 들일 수 있어요.
- 옮겨 넣거나 자라서 넓이가 모자라면 "울타리가 좁아요"가 뜨고, 18초쯤마다 울타리를 부수고 나가거나 앓아요. 계속 좁으면 건강이 떨어져 죽어요. 울타리를 넓히면 풀려요.
- 반쯤 넘게 자란 공룡은 손으로 들 수 없어요. 트랙터나 비행기를 타고 가까이 가서 [싣기], 옮길 울타리 안에서 [내려놓기]를 누르세요.

## 탈것으로 가축 옮기기

- 트랙터나 비행기를 탄 채로 가축과 공룡을 싣고 내릴 수 있어요.
- 비행기로 가축을 실어 육식 공룡 울타리 위에서 내려놓으면 먹이가 돼요. 하늘에서는 물리지 않아요.
- 싣고 있는 동안에는 탈것에서 내릴 수 없어요.

## 가축 사기

- 가축 칸을 누르면 설명 칸에서 들일 울타리와 수량을 고를 수 있어요. [−] [＋] [최대]로 수량을 정하면 값이 함께 바뀌어요.
