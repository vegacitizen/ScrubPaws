# v7.1.1 — 창고 메뉴 버그 수정, 도구 묶음

- 고침: [창고 열기]를 누른 손을 떼면 메뉴가 바로 닫히던 문제. 행동 버튼으로 여는 다른 메뉴(덫, 나무 뽑기 등)도 같은 문제가 있었어요.
- 창고의 도구가 낮 도구 · 밤 도구 · 범용 도구 세 묶음으로 나뉘었어요. 도구를 누르면 🔄 버튼의 순서에 넣거나 빼요(✅ 표시).
- 삽·곡괭이·낚싯대·그물·총은 범용 도구라 낮에도 밤에도 쓸 수 있어요.
- 아직 사지 않은 범용 도구는 🔒로 보여요. 상점 시설·장비 탭의 땅·자연, 호수, 도구·장비 묶음에서 사요.
- 밤이 되면 무엇을 들고 있든 횃불로 바뀌어요.
