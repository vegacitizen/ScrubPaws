# v8.5.0 · 도구 고르기와 메뉴 정돈

## 도구
- 화면 오른쪽 아래에 자주 쓰는 도구 세 칸이 늘 보여요. 낮에는 물호스 · 긁개, 밤에는 횃불 · 물호스가 고정이고, 셋째 칸에는 마지막으로 고른 도구가 남아요.
- 🧰 버튼(Q)을 누르면 도구 팔레트가 열려서 원하는 도구를 한 번에 골라요. 고르는 동안 시간은 멈춰요. 키보드는 1 · 2 · 3으로 세 칸을 바로 골라요.
- 창고에서 도구를 켜고 끄던 목록은 없앴어요. 도구와 씨앗은 모두 팔레트에서 골라요.

## 상점 · 창고 · 도감
- 상점 탭이 아이콘이 되었고, 아직 못 쓰는 탭은 보이지 않아요.
- 다음 레벨에 열릴 것은 이름 대신 🎁 미스터리 상자로 보여요. 레벨이 오르면 새로 열린 것을 아이콘 카드로 알려 줘요.
- 긴 설명 글은 [도움말] 안으로 접었고, 아이콘을 누르면 나오는 설명도 짧게 줄였어요([더 보기]로 펼쳐요).
- 칸이 많은 메뉴(시설 · 장비)와 도감은 묶음 단추를 눌러 한 묶음씩만 봐요.
- 모든 메뉴 위쪽에 ✕ 닫기 버튼이 생겼어요.

## 그 밖에
- 휴대폰에서도 일시정지 버튼이 보여요.
- 알림이 겹치면 지워지지 않고 차례로 나오고, 목표 패널을 가리지 않아요.
- 지도가 한 화면에 들어오고, 작은 화면에서 글자가 조금 커졌어요.
