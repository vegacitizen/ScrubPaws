# v5.1.0 — 아기 공룡, 살아 있는 먹이, 병원, 과일나무

## 공룡
- 공룡은 아기로 복원돼요. 값이 내려갔어요(프로토케라톱스 6,000 / 콤프소그나투스 3,000 / 트리케라톱스 14,000 / 벨로키랍토르 7,000 / 브라키오사우루스 28,000 / 티라노사우루스 15,000원).
- 육식 공룡은 다 크면 아기 때의 10배가 넘는 값에 팔려요(다 큰 값 36,000 / 84,000 / 180,000원).
- 육식 공룡은 살아 있는 가축만 먹어요. 아기 때는 닭, 조금 크면 양·염소·돼지, 다 크면 소보다 큰 가축이어야 배가 차고 빨리 자라요. 작은 먹이는 조금만 배가 차고 더디게 자라요.
- 육식 공룡은 같은 울타리의 가축과 사람을 모두 공격해요. 울타리 하나에 한 마리만 키울 수 있어요. 밤에는 자요.
- 물리면 병원에서 치료비를 내요(공룡 종류와 크기에 따라 400 ~ 12,800원). 창고 앞에서 다시 시작해요.
- 초식 공룡은 울타리 안의 다 자란 나무에서 먹어요. 필요한 양: 프로토케라톱스 1, 트리케라톱스 2, 브라키오사우루스 4. 소철 한 그루가 2, 과일나무가 1을 대요. 나무가 모자라면 여물통 먹이를 먹지만 더 빨리 배고파지고 더디게 자라요.
- 육식 공룡의 사진 관람료와 고기 판매는 없어졌어요.

## 묘목과 과일나무
- 씨앗·비료 탭에서 묘목을 사서 들판이나 울타리 안에 심어요: 사과(레벨 4), 배(6), 복숭아(8), 귤(10), 소철(7, 실험실 필요).
- 다 자라면 과일이 열리고, 따면 돈이 돼요. 한 울타리에 6그루, 모두 40그루까지.
- 울타리 안에 나무가 있으면 기린과 판다가 과일을 먹거나 나무를 타고, 그동안 1.5배 빨리 자라요.
