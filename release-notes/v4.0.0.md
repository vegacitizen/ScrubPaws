## v4.0.0 — 일꾼과 끝없이 커지는 농장

- 일꾼 고용: 농사꾼(물 주기·수확·다시 심기), 목동(달걀·털·젖 거두기), 사육사(먹이·물 채우기, 씻기기). 품삯을 주면 농장을 돌아다니며 일하고, 여럿이면 동시에 더 많이 합니다
- 자동화 장치 추가: 자동 세척기, 자동 수확기
- 시세: 가축과 산물 값이 날마다 오르내립니다
- 가축 품평회: 닷새마다 가장 잘 키운 가축으로 상금을 겨룹니다
- 전설 가축: 희귀한 어미에게서 아주 드물게 태어나는 보랏빛 가축 (값 20배, 도감 7칸 추가)
- 땅 넓히기: 살 때마다 농장이 넓어지고 밭과 울타리 자리가 늘어납니다. 횟수 제한이 없습니다
- 명성의 별: 최고 레벨 뒤에도 계속 쌓입니다
- 출석 선물
