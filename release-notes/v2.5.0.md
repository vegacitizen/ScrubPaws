## v2.5.0 — 풀과 물, 끈질긴 맹수

- 건초 더미가 쓰는 만큼 줄어듭니다. 들판의 풀을 베어 건초 더미에 쌓거나 바로 여물통에 놓습니다
- 창고 옆 물탱크: 호스를 쓰면 물이 줄고, 비면 펌프질로 지하수를 끌어 올립니다
- 여물통 옆 물통: 호스로 채우면 목마른 가축이 마십니다 (가축에게 목마름 추가)
- 맹수는 여러 번 쫓아야 달아납니다. 횃불로는 늑대 세 번, 곰 다섯 번. 한 번 쫓기면 물러났다가 다시 옵니다
- 새끼는 하루에 20%씩 자라고, 먹이·물·깨끗함이 갖춰지면 더 빨리 자랍니다. 잘 돌본 어미는 한 번에 여러 마리를 낳습니다
- 창고 메뉴에서 양털·우유를 수확합니다. 시간이 지날수록 많이 쌓입니다
- 가축을 한 마리씩 값을 보고 파는 메뉴
