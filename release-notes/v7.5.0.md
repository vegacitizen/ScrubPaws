# v7.5.0 — 넓은 세계

- 세계 크기 약 4배: 북부 숲 · 북동 산악(지나갈 수 없는 산, 보석 바위) · 서부 초원(자갈밭) · 동쪽 들판 · 남쪽 들판
- 큰 호수를 맵 오른쪽 아래로 옮기고 크게 (선착장·배·어시장은 이 호수에)
- 창고 서쪽에 저수지 낚시터: 다리·벤치·갈대. 물가와 다리 끝에서 낚시, 레벨 4에 작은 나무배가 자동으로 생겨 깊은 곳까지
- 저수지 물고기 10종: 깊을수록 큰 종류가 나오고 같은 물고기도 더 크게(cm) 자라 값이 올라요
- 미니맵(오른쪽 위) · 지도(누르거나 M 키) · 빠른 이동(정류장 7곳, 새 정류장은 한 번 가 보면 열림)
- 야생 동물이 맵 전체 서식지에 고루 살고 수가 늘 36마리 안팎으로 유지돼요 (새 종: 다람쥐·여우·노루·산양·야생 말·들소·늑대·곰·호랑이)
- 맹수(늑대·곰·호랑이·눈표범)는 다가가면 달려들어 습격(치료비)해요. 농장과 정류장 둘레는 안전
- 총 사냥: 큰 동물은 여러 발, 맞은 맹수는 사납게 달려듦, 잡으면 돈 + 고기(창고)
