# v8.10.0 · 아픈 가축 돌보기와 간소한 상태 표시

## 아픈 가축
- 생명이 절반 아래로 떨어진 가축은 **🏥 병원 표시**와 **하트 다섯 칸**이 머리 위에 떠요. 돌보지 않으면 하트가 하나씩 줄고, 다 사라지면 가축을 잃어요.
- 아픈 가축은 주저앉아 느릿느릿 움직이고, 많이 아프면(하트 2칸 이하) 옆으로 누워 꼼짝 못 해요.
- 아픈 동안에는 생명이 예전보다 천천히 줄어서 손쓸 시간이 있어요.
- **💊 응급약**(상점 → 가축 탭, 400원. 처음에 1개 있어요): 아픈 가축 옆에서 [💊 응급 조치]를 누르면 생명이 절반쯤 돌아오고 배고픔 · 목마름도 덜어 줘요.

## 간소한 상태 표시
- 가축 머리 위 그림은 지금 상태만 작게 보여 줘요: ❗ 놀람 · 🏃 탈출 · 🏥 아픔 · 🍴 배고픔 · 💧 목마름 · 🫧 더러움 · 거둘 것 · 💗 임신.
- 가축마다 뜨던 먹이 종류 그림과 "○○ 주세요" 말풍선, 돌봄 도구 그림은 없앴어요. 어떤 가축이 무엇을 먹는지는 상점의 먹이 · 씨앗 설명에서 볼 수 있어요.
- 화면 위 오른쪽의 배고픔 · 목마름 · 더러움 글자는 없애고, 아래 가운데 요약(🏥 🍴 💧 🫧 🧺)으로 모았어요.
