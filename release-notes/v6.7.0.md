# v6.7.0 — 가축과 교감하기

- 쇠스랑을 없애고 🧹 긁개를 넣었어요. 건초를 한 번에 3묶음 드는 것은 레벨 2부터 도구 없이 저절로 돼요.
- 🧹 긁개 (처음부터): 가축 옆에서 [긁어 주기]. 만족도 +15, 교감 +4, 60초 동안 1.3배 빨리 자라요. 같은 가축은 20초에 한 번.
- 🍪 간식 (10개 300원): 가축에게 주면 만족도 +20, 교감 +8, 15초 동안 졸졸 따라와요.
- 🎵 피리 (1,500원, 레벨 2): 불면 가까운 가축들이 모여들어 춤을 춰요. 모두 만족도 +10, 교감 +2. 25초에 한 번.
- 교감 (가축마다 0 ~ 100): 오를수록 더 빨리 자라요(100에서 +20%). 50이 되면 "친한 사이"로, 다가가면 반기며 따라와요. 100이 되면 "단짝"으로, 팔 때 값이 10% 올라요.
- 다 큰 육식 공룡은 긁거나 간식을 줄 수 없어요.
