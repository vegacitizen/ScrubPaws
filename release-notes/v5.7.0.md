# v5.7.0 — 창고 여러 채, 뿌리기 종류 나누기

- 창고 더 짓기 (레벨 6): 시설·장비 탭에서 고른 뒤 원하는 자리에서 [창고 짓기]. 값은 15,000 → 30,000 → 45,000원, 세 채까지 더 지어요(모두 네 채).
- 창고 한 채마다: 일꾼 +2명, 동시에 켜는 자동화 장치 +2대, 탈것 +1대, 작물 보관 +20칸.
- 자동화 장치는 이제 동시에 3대까지만 켤 수 있어요(창고 한 채 더 지을 때마다 +2대). 넘는 장치는 다음 아침에 꺼져요.
- 탈것은 창고 한 채에 한 대예요. 트랙터가 있으면 비행기를 사려면 창고가 두 채 있어야 해요(이미 가진 비행기는 그대로예요).
- 어느 창고에서나 도구와 먹이를 꺼내요. 비행기가 있으면 창고 메뉴에서 다른 창고로 바로 날아가요.
- 비행기 뿌리기를 물 / 비료 / 먹이로 나눴어요. 날면서 🔄 버튼으로 고르고 [뿌리기]를 눌러요. 물은 밭과 물통, 먹이는 여물통과 공룡 먹이 낙하예요.
