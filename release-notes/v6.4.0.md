# v6.4.0 — 아이콘 메뉴

- 상점과 창고의 목록이 아이콘 칸으로 바뀌었어요. 한 화면에 여러 줄씩 보여요.
- 칸을 누르면 아래 설명 칸에 이름·설명과 [사기] 버튼이 나와요. 산 뒤에도 같은 칸이 골라진 채로 있어 이어서 살 수 있어요.
- 조건이 안 맞는 칸은 흐리게 보이고, 누르면 까닭을 알려 줘요(돈이 얼마 모자라는지, 필요한 레벨·울타리·창고 단계, 일꾼 자리 등).
- 이미 가진 것은 연두색 칸에 ✔로 표시돼요.
- 시설·장비 탭은 접었다 펴지 않고 묶음 제목 아래에 모두 펼쳐 보여요.
- 긴 안내 글은 맨 아래 "도움말 보기"로 접었어요.
- 탭에 아이콘을 붙였고, 낮은 화면에서는 탭이 한 줄로 옆으로 넘겨져요. 상점 제목 줄을 줄여 목록 자리를 넓혔어요.
