# v8.13.0 · 맹수를 쫓는 개, 달라진 총

## 양치기 개
- 맹수가 농장에 나타나면 개가 무엇보다 먼저 달려가 물어요. 한 번 물 때마다 횃불 한 번과 같은 효과이고, 2.4초마다 다시 물어요. 늑대는 세 번 물리면 달아나요.
- 개가 여러 마리면 맹수를 나눠 맡아요.

## 총
- 가축과 개는 이제 총에 맞지 않아요.
- 대신 조준선 위에 울타리 · 나무 · 허수아비 · 장식 · 장작 더미가 먼저 있으면 총알이 거기서 멈추고 그것이 부서져요.
  - 울타리: 맞은 자리에 구멍이 나요(고쳐야 해요). 철 울타리는 총알을 튕겨 내요. 열려 있는 문과 이미 난 구멍으로는 총알이 지나가요.
  - 숲의 나무와 과일나무: 부러져요. 숲의 나무는 사흘 뒤 다시 자라요.
- 물건에 맞아도 총소리에 놀란 가까운 맹수는 달아나요(보상 없음).
