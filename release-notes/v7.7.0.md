# v7.7.0 — 화면 품질 보정

- 빛: 아침·낮·노을·밤에 따라 해의 색과 방향, 하늘빛이 바뀌고 먼 곳에는 옅은 안개가 낌
- 나무와 덤불: 위아래 명암이 있는 울퉁불퉁한 잎으로 바꾸고 바람에 흔들리게 함. 소나무는 층이 진 모양
- 땅과 길: 넓은 땅에 큰 얼룩을 넣고, 길은 가장자리가 자연스럽게 번지는 흙길로
- 물: 호수와 저수지에 잔물결 두 겹과 물가의 흰 거품 띠
- 낮에는 꽃가루, 밤에는 반딧불이 떠다님(저화질에서는 꺼짐). 화면 가장자리를 살짝 어둡게
- 그림자가 걸을 때 일렁이지 않도록 고정
- 이모지 그림을 3D 모형으로: 야생 동물 17종, 밭에 오는 새, 작물(새싹·자라는 중·다 자란 5종), 물고기 떼, 전시관 손님. 불은 직접 그린 불꽃
- 위 막대: 돈·레벨·날씨를 직접 그린 아이콘으로, 패널에 입체감. 소리·일시정지·도감·상점 버튼도 선 아이콘으로
- 목표 패널: 평소에는 지금의 목표만 보이고, 누르면 주문·미션·시세까지 펴짐(선택은 기억됨)
- 돈이 바뀌면 숫자가 굴러가고 번 돈은 동전이 날아와 쌓임. 경험치 막대는 부드럽게 참. 메뉴 창은 튀어나오듯 열림
- 나무·덤불의 도형 수를 줄여 한 화면의 삼각형이 약 43만에서 24만으로 줄어듦
