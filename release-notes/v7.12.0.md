# v7.12.0 — 남은 도형을 각진 로우폴리로

- 도형으로 만든 모든 객체(주인공, 닭·염소·낙타·기린·코끼리, 야생 동물 9종과 곰, 헛간과 시설 건물, 울타리와 여물통, 수레와 비행기, 허수아비 등)를 면이 각진 로우폴리 형태로 바꿈. 둥근 공·원기둥·둥근 모서리 상자를 면 수가 적은 도형으로 바꾸고, 면마다 따로 음영을 넣음
- 손에 든 도구 19종을 이모지 그림 대신 3D 모형으로(횃불·씨앗 자루·비료·물호스·쇠스랑·그물·삽·곡괭이·낚싯대·덫 3종·긁개·간식·피리·딱따기·징·허수아비 모자·사냥총). 횃불은 막대 위에 불꽃이 붙음
- 놓아 둔 덫을 3D 모형으로. 잡힌 동물은 그 동물의 모형이 덫에서 버둥거림
- 들판의 반짝이는 금빛 보석 모형으로, 부서진 울타리의 경고 표시와 전기 울타리의 번개 표시도 3D 모형으로
- 농장 과일나무를 숲과 같은 나무 모형으로
- 판다와 희귀한 춤추는 소의 예전 모형 파일(panda_model.js, cowdance_model.js)을 지움. 판다는 각진 도형 모형, 춤추는 소는 소 모형이 금빛으로 뛰며 춤춤
- 한 화면의 삼각형이 약 30만에서 24만으로 줄어듦
