# v7.0.0 — 땅과 자연

상점 시설·장비 탭에 "땅·자연" 묶음이 생겼어요.

## 개간과 바위
- 농장 둘레에 자갈밭과 바위가 생겼어요(첫 울타리 둘레는 비어 있어요). 자갈밭에는 씨앗을 뿌릴 수 없고, 뿌리려 하면 까닭을 알려 줘요.
- 🕳️ 삽 (800원): 자갈 옆에서 [삽질하기]로 치워요. 고철·구리·은·금·자수정이 나오기도 해요.
- ⛏️ 곡괭이 (2,000원, 레벨 3) · 강철 곡괭이 (6,000원, 레벨 7): 바위를 깨요. 작은 바위 8번, 큰 바위 20번, 집채만 한 바위 40번(강철은 절반). 큰 바위일수록 금·자수정·루비·다이아몬드가 잘 나와요.

## 땅 파기와 물
- 삽으로 빈 땅을 파요. 한 칸을 다섯 번까지 팔 수 있어요.
- 깊이 2부터 작은 동물, 3부터 중간 동물, 4(두 칸 이상 이어서)부터 큰 동물이 못 건너요. 야생 동물, 울타리 밖으로 나간 가축, 밤의 맹수에게 적용돼요(맹수는 한 단계 더 깊어야 해요).
- 깊이 5에서 지하수가 솟아요. 이어진 물이 1~2칸이면 웅덩이, 3칸부터 연못, 8칸부터 저수지예요. 물은 아무도 못 건너요.
- 삽을 든 채 구덩이 앞에서 행동 버튼을 누르면 메워요.
- 🚰 연못 물탱크 (6,000원): 물이 솟은 곳마다 하나씩. 물탱크 용량 +50, 물이 저절로 차요.

## 물고기와 낚시
- 치어를 사서 풀어요: 붕어(웅덩이부터), 잉어(3칸), 메기(5칸), 송어(8칸), 철갑상어(14칸). 물 한 칸에 두 마리까지 살아요.
- 물고기는 시간이 지나며 자라고, 같은 종류가 두 마리 이상 자라면 새끼를 쳐요. 붕어는 가끔 저절로 생겨요.
- 🌿 수초 필터 → ⚙️ 여과기 → 🏭 정수장: 수질 40% → 60% → 80% → 100%. 수질만큼 빨리 자라고 빨리 늘어요.
- 🎣 낚싯대 3종 (1,500 / 6,000 / 18,000원): 크기 3 / 6 / 10까지 낚아요. 값은 종류의 기본값 × 크기예요.

## 야생 동물과 덫
- 낮 동안 울타리 밖에 야생 동물이 돌아다녀요. 가축을 공격하지 않고, 다가가면 달아나요. 밤에는 사라져요.
- 총으로 잡거나(낮에도 총을 들 수 있어요) 덫으로 산 채 잡아요. 덫이 약하면 부수고 달아나요.
- 🪤 올가미 (400원, 레벨 3) · 📦 상자 덫 (1,500원, 레벨 6) · 🥅 대형 포획 틀 (5,000원, 레벨 9). 한 번 잡으면 없어져요.
