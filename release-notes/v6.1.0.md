# v6.1.0 — 트랙터 수확과 내리기

- 트랙터 수확: 트랙터를 타고 다 자란 작물 위를 지나가면 저절로 거둬 짐칸에 실어요. 짐칸은 건초와 따로 작물 24개(큰 트랙터 48개)까지예요.
- 내리기: 작물을 실은 채 도구 버튼이 [작물 내리기]로 바뀌어요. 누르면 트랙터 뒤에 종류별 더미로 내려놓아요.
- 창고에 넣기: 창고(어느 창고든) 옆에서는 버튼이 [창고에 넣기]로 바뀌고, 누르면 바로 창고에 보관돼요. 창고가 차면 남은 것은 짐칸에 남아요.
