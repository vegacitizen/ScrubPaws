# v8.4.0 — 비상업 조건 모형 제거

- v8.3.0에서 넣었던 비상업 조건(CC-BY-NC-SA) 모형 4종을 뺌. 앱과 저장소의 원본 폴더에서 모두 제거
- 낙타: Quaternius의 알파카(CC0)를 낙타 색으로 칠하고 등뼈에 혹 두 개를 붙여 만듦. 걷기 · 달리기 · 먹기 동작 있음
- 코끼리: 코드로 직접 만든 모형. 다리 · 코 · 귀 · 꼬리가 따로 움직이고, 먹을 때 코를 입으로 말아 올림
- 야생 들소와 야생 말: 이전의 CC0 황소 · 말 모형으로 되돌림
- v8.3.2의 내용 포함: 돼지 모형 복구
- 남은 조건부 모형은 출처 표기가 필요한 CC-BY 4.0 다섯 가지(기린 · 염소 · 하마 · 라마 · 양)
